# Проверка готовности к ModHub

Проверено 23 ноября 2026. Текущая сборка: **1.0.0.8**, автор **fireton**.

**Итог: описание и техническая упаковка подготовлены; полное соответствие ModHub пока не подтверждено. Остаются иконка, первый скриншот и официальный TestRunner.** Ничего не отправлялось на публикацию.

Источник: [официальный гайд GIANTS](https://forum.giants-software.com/viewtopic.php?t=209169), редакция 19.03.2026. Полный текст прочитан через печатную версию страницы. Примеры `descVersion` в гайде относятся к старым патчам; для этой установки использован фактический формат из игрового лога.

## Архив

Имя `FS25_AIUnloadThreshold.zip` соответствует префиксу FS25 и не содержит номера версии. Дескриптор находится в корне. Зарегистрированные Lua-файлы и XML профилей включены; ссылки на файлы существуют. CRC проверяется сборщиком. Обязательных внешних модов нет.

Иконка переименована в `icon_aiUnloadThreshold.dds`; сборщик берёт её имя из дескриптора. В игровой ZIP входят только дескриптор, Lua-скрипты, XML профилей и DDS-иконка. README, отчёты, скриншоты, исходный SVG, предпросмотр, тесты и инструменты сборки остаются в репозитории.

## Иконка — открытый вопрос

Активная пользовательская иконка технически исправна: 512×512, BC3/DXT5, без mipmaps, с прозрачными фоном, окном и центрами колёс. Визуально она согласована пользователем. Однако это **не совпадает с указанным в гайде форматом ModIcon — BC1**.

Подготовлен отдельный кандидат `modhub-icon-candidate/icon_aiUnloadThreshold.dds`: 512×512, BC1/DXT1, без mipmaps, на непрозрачном тёмном фоне. Он соответствует параметрам формата, но **не объявляется полностью соответствующим оформлению**: официальный фон-шаблон не применён. В активном моде сохранена согласованная прозрачная версия.

Рисунок получен из пользовательского `Tracing.svg`; при обработке менялись цвета и маски, использовалась векторная отрисовка. Генерация изображений ИИ не применялась. Происхождение первоначального рисунка и права на него отдельно не проверялись. Допустимость такой пиктограммы для скриптового мода стоит уточнить у команды ModHub: приведённый в гайде пример оформления ориентирован на технику.

## Скриншоты

Три готовых файла в `screenshots/modhub/` имеют 1600×900. Это реальные игровые кадры, обрезанные и уменьшенные без дорисовки и генерации. Оригиналы сохранены. Кадр меню показывает настройку и пояснение; игровые кадры показывают перегрузку.

**На первом кадре виден HUD.** Перед подачей желательно переснять первый игровой кадр со скрытым интерфейсом. Удалять HUD дорисовкой не следует. Рекомендация гайда сформулирована с оговоркой «если возможно»; она не заменяет оценку QA. Отдельный кадр меню уместен для демонстрации скриптового интерфейса.

## Проверки и ограничения

- Локальные Lua-тесты: 37 пройдены, включая поток загрузки, 100% и отдельные UI-контракты. Это не официальный TestRunner.
- Синтаксис Lua, XML/XSD, состав ZIP и DDS-заголовки проверены.
- Пользователь подтвердил работоспособность ожидания окончания погрузки и выхода по Esc на macOS. Полная матрица приёмки и Windows не заявлены как пройденные.
- Просмотренный игровой лог версии 1.0.0.7 содержит загрузку мода и добавление бегунка, без Lua errors. Новая локализация 1.0.0.8 в игре ещё не проверена.
- Официальный [FS25 Test Runner](https://gdn.giants-software.com/downloads.php) v0.9.24 рассчитан на FS25 1.25.1+ и Windows. В этом macOS-окружении не установлен и не запускался. Ссылка из форумного гайда ведёт на старую тему FS22; для проверки нужно брать актуальный FS25-инструмент из GDN.

Перед подачей остаётся выбрать вариант ModIcon/уточнить оформление, обновить первый кадр без HUD и выполнить актуальный TestRunner на Windows. Категория, иконка карточки и скриншоты добавляются в кабинете ModHub отдельно; эти поля здесь не заполнялись.
